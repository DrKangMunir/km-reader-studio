# KM-Reader Studio

An offline-first academic PDF reader and automated **Literature Review Synthesis Matrix** workspace built for researchers.

## Key Features
- **1-Click Auto Matrix:** Extracts a 5-pillar, 10-dimension literature synthesis (Context, Purpose & Framework, Methodology, Key Findings, and Critical Evaluation) with clickable `[1]–[10]` sentence jump-links anchored directly to the PDF.
- **Persistent Literature Matrix:** Stores extracted studies across sessions, supports merging saved `.json` / `.csv` matrices, and exports clean **CSV** and **A4 Landscape PDF** tables.
- **Cross-Paper Synthesis:** Compares consensus, contradictions, and research gaps across all studies in your matrix.
- **100% Local Privacy:** PDFs, highlights, sticky notes, and matrices stay locally on your device.

## Quick Start
1. **Use Online:** Open the live web app via GitHub Pages (works on Windows, macOS, and tablets).
2. **Install Desktop App (Windows):** Download the latest `.zip` from **Releases**, extract it, and double-click `Install-KM-Reader-Studio-Windows.bat`.
3. **Optional AI Extraction:** Click the model badge in the top bar to add your free Google AI Studio Gemini API key, or use the built-in offline extraction engine without an API key.
